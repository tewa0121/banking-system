# 🏦 Banking System - Full Stack Application

A complete banking system built with React.js, Node.js, Express, and MySQL.

## ✨ Features

### 👤 User Features

- 🔐 **Authentication**: Register, Login, JWT-based authentication
- 👤 **Profile Management**: View and update profile information
- 🔑 **Password Management**: Change password
- 💰 **Deposit**: Add money to your account
- 💳 **Withdraw**: Withdraw money from your account
- 💸 **Transfer**: Send money to other accounts
- 🏦 **External Transfer**: Transfer to other banks
- 📈 **Interest Calculator**: Calculate monthly and yearly interest
- 📊 **Transaction History**: View all your transactions
- 🌍 **Multi-language Support**: English, Amharic, Oromoo, Tigrigna, Somali

### 👑 Admin Features

- 📊 **Admin Dashboard**: View system statistics
- 👥 **User Management**: View all users
- 📋 **Account Management**: View all accounts
- 📝 **Transaction Monitoring**: View all transactions

## 🛠️ Tech Stack

### Frontend

- **React.js** - UI Framework
- **React Router v6** - Navigation
- **Axios** - HTTP Client
- **React Toastify** - Notifications

### Backend

- **Node.js** - Runtime Environment
- **Express.js** - Web Framework
- **MySQL** - Database
- **JWT** - Authentication
- **Bcrypt** - Password Hashing
